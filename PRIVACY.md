# Privacy Notes

Last updated: July 2026

YOLO Vision Assistant may process images, video frames, model files, and local runtime data depending on how it is configured.

## Public Repository

This public repository should not contain:

- private images or videos
- faces or identifiable personal media without permission
- API keys or service credentials
- private model outputs tied to real people or private locations
- local `.env` files

## Local Use

If camera, image, or video inputs are used locally, confirm that users understand what is being processed and where data is stored or transmitted. Do not upload private media unless the destination and permission are clear.
