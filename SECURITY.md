# Security Policy

Last updated: July 2026

This repository is a public experimental computer vision project. Security concerns include exposed credentials, unsafe media handling, dependency issues, and unintended publication of private images or videos.

## Reporting A Security Issue

Please report security concerns privately by email:

**majumdar.amrik@gmail.com**

Include the affected file, a short description, and steps to reproduce when applicable.

## Repository Safety Rules

- Do not commit API keys, tokens, or `.env` files.
- Do not commit private images, videos, or camera captures.
- Keep generated model files intentional and documented.
- Review backend routes before connecting external services.
